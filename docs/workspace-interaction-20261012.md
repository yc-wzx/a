# 工作台交互改进与开源复用

适用范围：AgileCampus 网站中的个人工作台。团队对外展示进度的腾讯文档主页是另一份资料。

## 这次新增了什么

| 功能 | 用户怎么用 | 数据来源 |
| --- | --- | --- |
| 个人概况 | 查看今天截止、逾期、本人待办、待修改成果和未读通知，点击进入相应区域 | 原有任务、成果和通知服务 |
| 下一步入口 | 优先打开逾期任务；其次处理教师反馈，再推进自己的未完成任务 | 固定的可解释规则，不调用大模型 |
| 任务筛选 | 按截止时间、项目、关键词筛选；无结果可清除筛选；超过八项可继续展开 | 本人当前可访问项目中的未完成任务，含子任务 |
| 快速查找 | Ctrl K 打开；中文关键词搜索；方向键选择，回车进入，Esc 关闭并恢复焦点 | 工作台已加载的项目、任务、迭代、成果和常用入口 |
| 我的项目 | 查看真实任务完成数；直接进入看板、个人规划和成果页 | 当前团队成员资格，最多六张活跃项目卡片；其余项目通过“查看全部”访问 |
| 今日日程 | 查看当天已登记的课程和临时事件；管理、导入日程 | 仅当前用户自己的日程，统一北京时间；未登记不等于空闲 |
| 重新规划提醒 | 日程变化后进入对应项目重新核对安排 | 已确认但课表版本过期的个人计划 |
| 迭代进度 | 查看目标、日期、主任务完成比例；展开更多迭代或翻页 | 原有迭代服务，保留主任务统计口径 |
| 教师反馈 | 打开明确的成果版本和教师意见，修改重交 | 原有成果版本与反馈服务；通知已读不会清除待修改成果 |
| 操作反馈 | 显示刷新进度与完成状态，提供焦点样式和页面引导 | 本次前端交互 |

## GitHub 调研与取舍

### 实际引入：cmdk 1.1.1

- 仓库：[pacocoursey/cmdk](https://github.com/pacocoursey/cmdk)，MIT。
- 用于快速查找的搜索、分组、空状态和键盘选择。
- 外层采用浏览器原生 dialog，负责模态焦点约束、Esc 关闭和焦点恢复。菜单只导航，不执行删除或修改业务数据。
- 搜索范围是工作台已经授权并加载的数据，并非全站全文搜索。

### 实际引入：Lucide React 1.55.0

- 仓库：[lucide-icons/lucide](https://github.com/lucide-icons/lucide)，ISC，部分 Feather 衍生图标保留 MIT 条款。
- 按需引用工作台图标；每个操作仍有中文文字或无障碍名称，不能只靠图标和颜色理解。
- 许可证原文保存在 `docs/licenses/`。

### 参考设计：shadcn/ui

- 仓库：[shadcn-ui/ui](https://github.com/shadcn-ui/ui)，MIT。
- 参考其概况卡片、主要内容与辅助内容的层次，按现有暖白、藏青设计系统实现。
- 没有复制整套后台模板或示例营业收入、增长率图表，也没有安装其整套依赖。课程项目需要的是实际任务与反馈。

### 本次不引入：React DayPicker

- 仓库：[gpbl/react-day-picker](https://github.com/gpbl/react-day-picker)，MIT。
- 适合交互式日期选择。当前工作台只需要查看今日议程，使用已有课表数据即可；日期选择器可在后续完整课表界面中考虑。

## 为什么适合交互设计课程展示

这次调整解决三件事：先识别需关注的工作，再缩小任务范围，最后直接进入操作。概况、下一步入口、任务区和辅助信息分开呈现；空状态给出明确去向；搜索、键盘操作和刷新提供即时反馈。

实际试用时可让三位同学各完成：找出今天截止的任务；通过关键词进入任务详情；找到教师要求修改的成果；查看自己的课表。记录操作时间、是否走错入口及是否需要他人提示。这些是待开展的真实用户试用，不应把自动化测试写成同学的体验反馈。

## 数据与兼容性

- 复用现有任务、迭代、成果、通知与个人日程接口；没有数据库结构变更。
- 项目卡片查询在同一 SQL 快照核验当前成员资格并统计任务；退组与归档项目不出现在卡片中。
- 单项加载失败显示失败提示和未知数，不伪装为零条数据。
- 日程只在本人的工作台显示，团队共享隐私规则保持原服务定义。
- 项目卡片统计含子任务；迭代统计只算主任务，两处都说明口径。
- 按当前约定验证电脑端，不新增手机端验收要求。
