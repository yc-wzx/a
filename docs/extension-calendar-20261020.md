# 个人日历、持续订阅与跨设备筛选（2026-10-20）

## 本轮交付

之前已有 ICS／CSV 文件导入、截止日期 ICS 导出和周／月／事项日历。本轮增加以下能力，不把原功能重复计为新增。

| 功能 | 操作与边界 |
| --- | --- |
| ICS 持续订阅 | 「课表与日程 → 外部日历连接与持续订阅」填写 HTTPS 地址，明确授权后连接。后台定期读取，手动可立即读取；不向来源写入。 |
| 标准 CalDAV | 填写具体日历集合地址、账号、应用专用密码。使用标准 REPORT 读取、PUT 发布；不需要 Google／微软 OAuth 应用。 |
| 显式双向同步 | 读取外部变化到本地；在连接卡片内展开「发布本人手动日程」，逐条选择并确认发布本人手动／临时日程。随后可推送本地更新；外部更新也可回流。不会自动发布课表、任务或私人工作计划。 |
| 只读订阅地址 | 为个人日程生成独立、可撤销的地址。默认仅「忙碌」和时间，可另选公开名称。完整地址仅创建时显示，不使用登录 token，数据库只保存 token 哈希。 |
| 日历拖动改期 | 本人手动日程和有效已确认工作段显示 ↕。拖动至周日历时段或月日历日期，先检查冲突，再确认保存；点击 ↕ 输入时间是键盘替代方式。 |
| 常用筛选跨设备 | 筛选保存到账号并按项目隔离，最多 12 个。保存筛选、分组、视图和排序；任务内容、打开的任务 ID 和未知 URL 参数不保存。旧浏览器筛选可显式导入，原数据保留。 |

## 隐私与同步规则

- 每个连接属于个人账号，最多 5 个。日历地址可能带私密 token，因此地址和 CalDAV 凭据都使用 AES-256-GCM 加密；不在连接列表、日志或错误信息里返回秘密。密钥优先使用 `CALENDAR_ENCRYPTION_KEY`，未设置则从已有 `AI_SETTINGS_ENCRYPTION_KEY` 派生独立用途的密钥。
- 只允许标准 HTTPS 公网地址。共享 `safeFetch` 检查 DNS 的全部解析结果，固定已验证的连接 IP；拒绝内网、跨域携带凭据和过长／超时响应。CalDAV 不跟随重定向，返回的资源必须处于所选集合内。
- XML 拒绝 DTD／实体声明，限制大小与资源数量。课程重复规则使用现有 ICS 校验，只支持当前明确支持的普通按天／按周规则；不会默默近似复杂重复日程。
- 后台只读取最近 7 天至未来 180 天，默认不共享到团队。定时入口通过 `runCalendarRefreshBatch()` 接入既有 cron；每轮最多读取 12 个到期连接，并发 3 个，超过 60 秒不再开启下一组。单次网络请求超时 6 秒，ICS 最多一次重定向。成功读取时间与尝试时间分别记录，失败来源也会节流，不长期占据队首。
- 来源日程的名称和时间保持只读；在已登记日程中可单独允许／停止向已选团队共享模糊忙碌时间，不公开具体名称。共享标记是本地设置，来源更新不会替换该选择。
- 来源取消／删除时，仅移除这个连接中未改动的来源副本；本人手工发布的日程保留，并报告需要核对。断开连接时可选择保留副本（转为手动）或移除来源副本；两种操作都不删除来源事件。
- 本地与来源都修改同一日程时，保留本地并报告冲突。推送使用来源 ETag；HTTP 412 不会重试覆盖。来源缺少可用 ETag 时禁止后续覆盖更新。
- 双向发布范围限于逐条明确选择的本人手动／临时日程。外部导入的重复课程保持只读，请在来源日历修改，避免误改整组课程。没有 Google／Outlook 专用 OAuth 或会议邀请管理，也不会对来源执行 DELETE。
- 只读地址默认模糊名称，持有地址即可访问；应视为可撤销共享凭据。撤销后新请求失效，无法远程清除其他日历已经缓存的旧内容。只包含个人课表／手动日程，不包含项目任务和私人工作计划。

## 日历改期规则

修改以 15 分钟为单位，保持原时长。预检只给出提案，确认时再次读取版本并检查冲突。

- 仅操作当前账号的手动／临时日程，以及仍有效的已确认工作段。
- 外部导入日程、任务截止、里程碑、迭代和项目节点不会出现拖动入口。
- 工作段须在原计划范围、可投入时间和每日时长内，不能与已登记日程或其他工作段重叠，不能越过任务／阶段／项目截止日。
- 个人计划、成员身份、任务指派或日期改变导致原计划失效时，先要求重新核对计划。
- 工作段改期不会修改项目任务的截止日期，也不向来源日历自动推送。
- 服务端幂等请求和乐观版本检查防止重复保存及多设备覆盖。
