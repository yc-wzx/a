# 任务协作、项目文档及界面改进上线记录

2026-10-13 已上线至 [AgileCampus](https://weidu-agilecampus.pw)。应用版本：`90d4efa687ecc08b15d19bcc1c87bd31a09195d4`。

## 本批完成内容

已完成任务功能 **1、2、3、5** 与文档功能 **D1–D5、D7–D11**：检查清单、进行中数量软提醒、任务关注、资料关联，以及富文本、多人编辑、版本差异与恢复、段落评论回复、目录检索、双向任务关联、共享与私有权限、Markdown、打印、回收站、个人 AI 选区预览。

项目、团队和通知目录增加真实统计、筛选及操作入口。通知按日期分组并支持项目范围已读；页面操作指引统一放进「新手教程」，使用指南按管理员、成员、指导教师组织为正式章节。详见 [界面与教程说明](course-ui-handbook-20261013.md) 和 [本批功能与试用流程](course-documents-20261012.md)。

上线验证中修复文档时间与通知来源问题：文档时间统一北京时间和固定格式，避免服务器与浏览器首次渲染不同；通知已读请求采用配置的公网来源校验，适配 Cloudflare 转发，同时继续拒绝跨站请求和伪造来源。通知界面使用现有 Server Action，在同一次响应中重验并更新页面，处理中状态持续到列表更新。
