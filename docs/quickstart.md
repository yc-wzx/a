# AgileCampus 五分钟快速上手

网站：https://weidu-agilecampus.pw 。每个人注册自己的账号；电脑浏览器使用即可。登录后点击顶部「新手教程」，或「页面引导」查看当前页面的操作入口。

## 先用一分钟认识工作台

1. 查看顶部的需关注事项，再从蓝色「下一步」入口打开任务或教师反馈。
2. 在「我的任务」切换今天截止、逾期等条件，也可以选择项目、搜索关键词；找不到时清除筛选。
3. 按 Ctrl K 打开快速查找，用方向键选择，回车进入；Esc 关闭。
4. 在「今日日程」核对自己的课程与临时事件。日程变化后按提醒重新规划；完整日程仅自己可见。
5. 项目卡片可直达任务看板、个人规划和成果页；右上角刷新按钮重新读取最新数据。

## 负责人

1. 在「团队」创建团队，把邀请码发给组员和老师。
2. 在成员管理为老师设置导师角色；负责人为管理员，组员为学生。
3. 从团队打开项目列表，创建课程项目。使用课程模板时会提供四个建议阶段，可以删去不需要的里程碑。
4. 在项目看板创建任务，填写任务标题、负责人、日期和完成标准。点击任务卡片进入详情，修改、讨论或删除。
5. 展示前打开「成果」「周报」「过程证据」，核对实际提交和操作记录。

## 组员

1. 注册并用邀请码加入团队，在工作台找到自己的任务。
2. 点击任务卡片查看要求，遇到问题在任务评论中讨论，推进任务状态。
3. 在项目「成果」登记文档、PPT、视频或代码链接，保存草稿后正式提交。
4. 老师退回后查看反馈，开始新版本草稿、修改并重新提交。正式提交和验收通过是两个步骤。
5. 需要排期时，在账户菜单「我的课表与日程」导入课表；项目「AI 与草案」进入个人短期计划，选择任务和工时、预览再确认。突发事件添加到日程后可以重新规划，确认新计划才替换旧安排。

## 指导老师

1. 注册、加入团队，由管理员设置为导师。
2. 在教师项目总览查看项目进度与阶段成果。
3. 成果详情查看正式版本，填写验收通过或退回意见。
4. 在任务评论或项目公告中补充指导。导师可指导和验收，任务和里程碑的增删由有权限的成员执行。

## 里程碑、任务和迭代有什么区别

| 名称 | 例子 | 如何使用 |
|---|---|---|
| 项目 | 这学期的小组网站 | 承载整个团队的工作 |
| 里程碑 | 需求分析、中期展示、最终展示 | 项目看板中的阶段节点，管理员可删除 |
| 任务 | 完成登录页面 | 点击卡片查看详情、修改或删除 |
| 迭代 | 这一周完成登录和任务详情 | 短周期工作安排，在「任务池与迭代」管理 |

删除里程碑前会显示关联数量，确认后解除当前关联；任务、成果和历史版本保留。删除主任务会同时删除它的子任务，确认前核对任务名称。导师无任务删除权限，归档项目不能修改。

## 配置自己的 AI 助手（可选）

1. 在账户菜单进入「设置 → 我的 AI 助手」。
2. 选择 DeepSeek、阿里云百炼、硅基流动或 OpenAI。其他兼容接口需要负责人先开放地址。
3. 从自己服务商的 API 控制台取得密钥和模型名称，填写后保存。设置助手名称及表达偏好，例如「用适合大二学生理解的中文，分步骤说明」。
4. 点击「测试已保存的连接」。测试会发一条短消息，按服务商的 API 规则计费；普通聊天会员不等于 API 额度。
5. 回到项目即可使用个人助手；迭代草案和课表规划也用本人的配置。更换服务商时填写对应的新密钥；同一服务商修改设置时密钥留空可保留原值。
6. 可以替换密钥或删除自己的 AI 配置。页面不回显已保存密钥，删除配置不会删除聊天或项目数据。

聊天默认个人会话，仅本人可见；需要全组讨论时主动选「项目共享会话」。AI 草案必须人工确认才写入业务数据。没有 API 密钥也能管理任务和成果，并使用规则规划。

课表和私人事件默认私有，只有本人主动共享的模糊忙碌时段才向团队展示。周报只整理真实记录，没有操作时不会自动编造进度。
