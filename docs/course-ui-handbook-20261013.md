# 项目、团队、通知与新手教程界面改进

在原业务和权限基础上完善电脑网页。界面显示已有数据，不填写虚构的进展、评分或活跃趋势。

## 项目

项目目录显示参与项目、进行中项目和任务完成数量；任务数量包含子任务，成果通过率不与它混合。可搜索名称、团队与描述，按团队、状态筛选，按创建顺序、结束日期或名称排列。筛选不会改变顶部总体统计，列表明确显示筛选后的项目数。

卡片提供团队、说明、进度、进行中任务数和结束日期，可直接进入概览、任务、项目文档及成果。没有任务或日期时明确提示。

## 团队

展示真实成员数、项目数、进行中项目数和当前账号角色；支持名称与角色筛选、复制邀请码，以及成员、日程、资源和标签入口。创建与加入表单集中在右侧，提供必填标签、处理中状态与错误反馈。

所有统计只读取当前账号所属团队；项目负责人职责和团队管理员权限明确区分。原角色管理、邀请码加入规则保持不变。

## 通知

按发生日期分组，展示类型、所属项目、未读状态、时间和来源。顶部区分「所有项目未读」「当前筛选结果」「本页消息」。支持项目范围与未读过滤、来源跳转、单条及批量已读、分页。

选择项目后，批量已读只处理该项目已有通知；切换范围重置分页。来源删除后保留记录并提示。已读操作不会完成任务或修改成果验收状态。

## 教程与页面操作指引

导航只保留一个「新手教程」菜单，内含「使用指南与角色流程」和「当前页面操作指引」。操作指引仍可随时启动、退出，不再作为独立导航入口。

使用指南以正式章节组织：开始使用、角色流程、项目与任务、文档协作、成果与反馈、通知、个人 AI 与日程、常见问题。区分负责人／管理员、成员和指导教师的权限与操作；补齐本批文档功能，取消「五分钟」「四个词就够了」等表述。

## 文档首次加载修复

生产服务器和电脑默认时区不同，原文档列表和历史时间可能触发 React 首次渲染不一致。文档时间改为统一北京时间和固定格式，服务器与浏览器使用同一规则，没有隐藏警告。

发布和浏览器验证见本轮上线记录；课程同学真实试用与个人模型效果另行记录。

本地生产运行模式已通过项目筛选、团队邀请码、通知项目范围已读、教程菜单与角色目录等 7 项浏览器检查；在 1366 与 1440 像素电脑宽度没有页面横向溢出。服务器使用 UTC、浏览器使用北京时间时，文档首次加载与界面操作没有未捕获异常。相关业务专项测试 58 项通过。
