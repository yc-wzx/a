# 任务协作与个人助手交付说明

本批在现有 AgileCampus 上增量完善，供电脑浏览器使用。

## 用户操作

1. 打开任意任务，显示居中双栏窗口。左侧修改任务或提交成果，右侧始终保留沟通区。拖动中间分隔线可调整宽度，左右方向键也可操作；双击恢复默认比例，当前浏览器记住比例。
2. 新建和编辑任务均可勾选多个执行成员。各成员的待办、任务日历和短期规则规划使用同一条任务；项目总任务数保持一条。成员工作量表示参与任务，不是贡献分数。
3. 左侧默认只展示标题、状态、截止日期、执行成员和描述。优先级、里程碑、起始日和完成记录折叠到“更多设置”；检查清单、资料、文档、阻塞、标签、依赖及删除入口保留。
4. “提交成果”中填写完成说明或成果链接任一项，直接进入原有正式版本与教师审核流程。任务标题和阶段自动带入，不重复填写。仅说明的成果会指向原任务作为查看入口。提交成果不自动改变任务状态，也不代表教师已通过。
5. “团队评论”供全队及老师查看和回复。“任务讨论”供任务执行成员、发起人和明确被邀请的人协商。发起人可邀请或移出额外讨论成员；移除执行成员或离组后，后端重新检查访问权。老师或管理员角色本身不授予讨论访问权。
6. 评论和讨论提供回复、提及、收到及独立未读状态。页面可见时约每1.8秒检查更新，切换页面及断开连接后重新鉴权；发送失败保留输入，重试使用同一请求标识防止重复。
7. 需要公开讨论结论时，点击“向全队发布结论”，自行整理文字并点击“确认公开”。不会复制私密聊天内容，也不会把讨论自动放进团队通知、过程证据、导出或 AI 上下文。
8. 工作台及顶栏的“我的助手”进入 `/assistant`。选定项目后，可以新建、切换、改名、删除个人对话；项目对话支持流式输出、停止、复制及失败重试。任务草案仍可编辑，确认后才写入。
9. 在右侧“我的记忆”中主动添加、编辑、禁用或删除偏好，可选择全部个人项目或指定项目。禁用和删除后不再加入新回答；失去项目权限的记录不再提供给助手。当前项目进度每次重新读取，不把旧状态当成记忆。
10. 资料问答继续使用原有的资料选择和引用机制，项目迭代草案与个人规则规划入口保留。

## 权限与兼容

- 原有团队评论保留在公开评论中，历史数据不搬进私密讨论。
- 数据库新增任务执行成员、讨论消息/邀请/收到/已读、个人记忆与请求记录。原单人指派会自动补入成员表；旧单人接口继续兼容，新接口增加可选 `assigneeIds`。旧接口明确改派时按单人改派处理，防止旧执行成员残留。
- 所有私密讨论读写和请求重放均重新检查团队关系与当前参与资格，无教师或管理员角色绕过。归档项目保留历史，只读。
- 每个账号继续使用本人配置的模型与加密密钥，没有配置时明确展示设置入口。演示账号按既有要求展示入口和规则规划，不新增共享密钥。
- 个人记忆保存在现有 PostgreSQL；最多保留100条，新回答使用最近启用的30条并限制上下文长度。没有引入向量数据库、独立聊天服务或完整编码代理运行时。
- 聊天交互参考既有官方平台研究；只借鉴适合课程项目的交互，未复制整套产品或私有代码。资料见前期 REA 调研，不把公开帮助页当作他人内部实现的证据。

## 验证与发布

新增服务测试覆盖共同指派、项目计数、旧接口改派、讨论隐私、教师与管理员隔离、明确邀请和撤销、离组、跨频道回复、重复消息、归档只读、个人历史与记忆，以及流式输出和中止。成果提交测试核对正式版本、重复提交和教师审核。

本地 Edge 多账号验证包括拖动和键盘调整、共同指派保存、另一账号自动收到评论/讨论、教师无默认讨论权限、手动公开结论、仅完成说明提交、个人助手入口、记忆禁用以及四种桌面宽度。真实 AI 输出使用可控测试模型验证；没有替演示账号配置真实供应商密钥。

发布使用 Linux CI 构建镜像，服务器只加载已验证镜像并执行增量迁移。发布前备份数据库及环境配置，保留上一版镜像和回滚流程；账号密码、个人密钥、原有任务和文档不重置。
