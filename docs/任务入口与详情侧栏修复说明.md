# 任务入口与详情侧栏修复

原行为：工作台等页面的任务链接先进入项目任务页，再打开详情侧栏；迭代页面的部分链接还会整页刷新。查看一个任务后容易丢失原来的页面位置和筛选。

修复后的交互：

- 普通点击任务：在当前页面打开一个详情侧栏。
- 关闭侧栏：保留原页面、筛选条件、排序和滚动位置。
- 浏览器后退关闭侧栏，前进恢复侧栏。
- Ctrl 点击或在新标签打开：仍使用原项目任务链接；分享链接可直接访问和刷新。
- 点击项目：正常进入项目页。
- 在侧栏保存任务：刷新当前页面的任务信息；原角色权限和服务端校验继续生效。

覆盖工作台及快速查找、成员个人主页、项目待办与工作量、迭代、个人计划、成果反馈、文档关联、通知和过程证据；看板、列表、甘特图共用登录布局中的一个侧栏。

本地验证：746 项回归通过，2 项真实模型测试跳过；新增 7 项任务导航测试包含在其中。TypeScript、改动文件 ESLint 和生产构建通过。电脑浏览器通过 24 组入口、历史记录、链接和角色检查，没有页面错误。隔离数据库中另验证了工作台侧栏保存后刷新，并恢复了测试任务标题。
