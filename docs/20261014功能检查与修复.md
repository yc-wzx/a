# 功能检查与修复（2026-10-14）

| 问题 | 修复后的行为 |
| --- | --- |
| 保存标签与依赖提示缺少优先级，无法保存 | 使用独立关联接口，只修改标签和后置任务，保留描述、负责人、日期等字段；校验版本与权限，失败整体回滚 |
| 侧栏组件标识重复，连续刷新可能产生重复内容 | 为检查清单、任务表单、关联表单和讨论使用各自唯一的标识 |
| 从评论通知打开任务丢失评论位置 | 保留通知中的评论目标，定位对应评论，关闭后返回通知列表 |
| 详情请求失败后一直加载；保存、删除、阻塞按钮卡住 | 显示失败提示并恢复按钮；详情可重试，保存失败保留输入，不把未确认的写入当成成功 |
| Tab 键能进入模态侧栏背后的页面 | 打开后将焦点移入侧栏，Tab/Shift+Tab 在侧栏中循环，关闭后恢复焦点和滚动 |
| 资源占用时间依赖服务器或浏览器时区 | 录入、此刻按钮和显示统一使用北京时间，新登记记录按正确的时间存储 |

检查范围：桌面浏览器中的老师、学生、管理员三个角色，各 30 个主要页面；任务新增、连续关联保存、清空关联、错误恢复、删除和里程碑新增/删除在独立本地数据库执行。线上验证只读取演示数据。

测试：757 项回归通过，2 项需要真实模型密钥的测试跳过；另通过新增 3 项资源时间测试和原资源业务回归，唯一通过测试合计 760 项。详情保存验证覆盖字段保留、重复请求、并发版本冲突、整体回滚、跨项目/跨团队拒绝、教师只读和归档限制。

没有新增依赖或数据库迁移。新增 `saveTaskAssociationsAction(projectId, taskId, input)` 使用原五种 `Result` 错误码；旧接口保持兼容。关联输入及版本要求见 `src/contracts/task-associations.ts`。
