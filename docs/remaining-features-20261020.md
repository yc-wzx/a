## 已有功能的扩展边界

| 扩展 | 目前完成到哪里 |
| --- | --- |
| 真实第三方 CalDAV 互通 | 标准协议和冲突回归已完成；尚未绑定用户的实际服务商账号。需要具体集合地址与应用密码实测。 |
| Google／Outlook 专用 OAuth、复杂循环与会议邀请 | 当前采用标准 ICS／CalDAV；没有专用账号授权向导、所有重复例外规则或外部会议邀请管理。 |
| 全量离线文档库 | 已支持本人未确认修改的持久恢复；不能在完全离线时首次打开任意文档，也不能保证清除浏览器数据后仍可恢复。 |
| Office 在线编辑／转 PDF | PPT、Word、Excel 可以上传下载；图片和 PDF 可以预览，Office 不在站内直接编辑或转换。 |
| 外部私有资料自动读取 | 只预览公网可访问资料；不登录第三方账号读取其私有文档。 |
| 跨团队校园设备目录 | 当前冲突检查限定团队内同名资源，尚未建立学校统一设备实体与跨团队授权。 |
| 历史燃尽数据补录 | 从实际采样开始积累，无法还原上线前未记录的每日状态。 |
