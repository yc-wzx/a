# 唯笃队：任务协作与项目文档本批交付

本批增加确认的任务功能 **1、2、3、5** 和文档功能 **D1–D5、D7–D11**。原看板、迭代、成果审核、课表和个人 AI 继续使用。本批编号与此前“任务三视图”等候选编号分开。

## 已实现

| 编号 | 功能 | 具体操作 |
|---|---|---|
| 1 | 完成检查清单 | 任务详情添加、修改、勾选、删除检查项，显示完成比例；不代替子任务，不改变原审核规则。 |
| 2 | 进行中数量提醒 | 管理员设置建议上限，留空关闭。统计全项目进行中主任务，不受筛选影响，超过只提醒。 |
| 3 | 关注任务 | 主动关注或取消；状态、完成、阻塞及解除阻塞通知进入现有通知中心，去重、排除本人及离队成员。 |
| 5 | 关联资料 | 任务详情关联已有会议资料、资料链接、正式成果版本，支持打开和解除；拒绝跨项目及私有成果草稿。 |
| D1 | 在线编辑 | 项目侧栏 → 项目文档。支持标题、正文、粗体、列表、检查项、表格、代码、链接、图片网址、`/` 快捷插入和保存状态。 |
| D2 | 多人编辑 | 两人同时打开同一文档，看到在线成员与光标，修改合并；断线时保留页面内容，重连后继续保存。 |
| D3 | 历史版本 | 保存命名版本，查看正文、中文增删差异、导出、恢复。恢复前留存当前稿，其他在线成员重新打开，旧会话不能混回旧稿。 |
| D4 | 段落评论与回复 | 点击或选中段落 → 评论当前段落。支持回复、解决、重新打开、按权限删除。原段落删除后保留引用；原评论删除后回复仍保留，不显示被删正文。 |
| D5 | 目录与搜索 | 按目录分类、标题和正文搜索、最近修改排序、50 篇一页；未授权的私有草稿不进入结果和数量。 |
| D7 | 文档关联任务 | 文档“任务”面板选择现有任务，两边互相跳转。 |
| D8 | 分享与权限 | 文档“设置”选择项目共享或个人草稿，阅读／评论／编辑三档及指定成员授权。教师默认可评论，明确授权后才能编辑。 |
| D9 | Markdown 与打印 | 目录导入 `.md`，正文导出 Markdown、浏览器打印；不引入 Office 编辑服务。 |
| D10 | 回收站 | 文档设置中移入回收站，目录回收站恢复；保留正文、评论、版本和任务关联。 |
| D11 | 个人 AI 写作 | 配置自己的助手 → 选中文字 → 润色／总结／建议 → 预览 → 确认替换或复制；可取消，不自动改全文。 |

## 3–4 人真实试用

使用电脑网页。甲任负责人、乙任组员、丙任教师，第四人可记录问题；每人用自己的账号。

1. 甲创建两项任务，添加、修改、勾选、删除检查项。乙关注一项，甲改变状态或阻塞，乙检查通知。甲设置数量提醒，验证超出后仍能移动任务。
2. 甲创建“交互设计说明”，试标题、列表、表格、代码和图片网址。乙同时编辑，确认双方内容最终都在。乙断网后输入一段，再联网，核对正文一致。
3. 丙默认不能改正文，但能定位段落评论。乙回复，甲解决并重新打开。删除原段落、原评论分别试一次，检查引用失效提示及回复保留。
4. 甲保存“展示前版本”，继续修改、查看差异、恢复；乙旧页面应停止同步并提示保留未保存稿、重新打开。
5. 甲将文档关联任务，从任务详情再打开。改为个人草稿，不授权乙和丙，二人搜索不到且旧网址也不能读取。甲移入回收站再恢复，核对正文与版本。
6. 导入包含标题、检查项、表格的 Markdown，导出核对并预览打印。已有个人 AI 配置的成员先取消一次预览，再确认一次，检查只有选区改变。

问题只记录角色、页面、操作步骤、期望、实际结果、截图及能否重现。不要在群里发送密码或 API 密钥。

## 实现边界

- 复用 Tiptap、Yjs 的免费开源能力；HTTP 轮询约每秒同步，不另建 WebSocket 服务。
- 离线内容保留在当前页面；关闭或刷新前可复制或下载未保存副本。没有承诺关闭浏览器后的离线编辑。
- 当前显示最新 100 个版本、500 条评论，历史仍在数据库。批注定位到段落，不做任意字符范围定位。
- 图片使用 HTTP/HTTPS 网址。Markdown 不携带协作权限、版本历史或精细布局；复杂合并表格可能简化。
- AI 只发送本次选中文字，不自动发送全文或其他个人资料。个人密钥加密保存、无团队共享密钥回退。真实模型质量、额度及网络需实际试用，自动化不冒充真实调用。
- 归档项目文档只读；读取、同步、评论、权限、导出、恢复均检查当前成员。负责人不能自动读取别人私有草稿。

## 开发交接和验证
