# 本轮课程协作功能补全（2026-10-20）

在现有 AgileCampus 上增量增加，面向高校师生的桌面网站。原有任务、成果审核、文档、个人 AI 和课表规划继续使用。

## 新增功能与操作入口

| 新增内容 | 从哪里使用 | 完成的操作 |
| --- | --- | --- |
| 文件附件 | 任务、任务成果、在线文档、成果、会议与资料 | 直接上传图片、PDF、PPT、Word、Excel、文本；图片和 PDF 站内预览，其他文件下载。上传任务成果文件后自动填入链接。单个 20 MB；沿用所属内容的权限。 |
| 关闭浏览器后恢复未保存文档 | 再次打开原文档 | 提示发现本地草稿，先查看或下载，再明确合并。只恢复本人未确认的改动；不覆盖整篇线上正文。 |
| 外部日历持续订阅 | 课表与日程 → 外部日历连接与持续订阅 | 连接 HTTPS ICS 地址，后台定期读取；显示读取结果，可手动刷新或断开。文件导入仍是一次性快照。 |
| 标准 CalDAV 同步 | 同上，选择 CalDAV | 读取外部日程；逐条明确选择本人手动日程发布到来源，后续可以推送更新。双方同时修改时保留本地并提示核对，禁止无条件覆盖。 |
| 可撤销的只读日历地址 | 外部日历连接页 → 只读订阅 | 默认只公开“忙碌”和时间；可明确选择公开名称。地址独立于登录凭据，可随时撤销。 |
| 日历拖动改期 | 工作台日历中带 ↕ 的日程或工作段 | 拖动到日期／时段，检查冲突后确认；也可点击 ↕ 用键盘输入。只改本人允许调整的安排，不修改任务截止日。 |
| 邀请管理与审核 | 团队 → 团队设置与加入审核 | 设置邀请码期限、关闭、刷新、启用审核；申请通过前不能读取团队项目。 |
| 团队归档与解散 | 团队设置 → 团队归档与解散 | 先归档所有项目和团队，再查看删除范围、输入名称确认解散。保留成员个人账号、个人课表和其他团队。 |
| 常用筛选跨设备 | 项目任务页 → 常用视图 | 筛选保存到账号、按项目隔离；新设备登录后可用。旧浏览器内的视图可主动导入。 |
| 公开资料预览 | 会议与资料 → 读取公开预览 | 读取公开网页的标题、说明，或在站内阅读公开 PDF。需要外部账号的内容仍打开原链接。 |
| 成果和答辩证据 CSV | 成果列表、成果证据、过程证据 → 导出 CSV | 按当前筛选导出中文表格，兼容 Excel／WPS；不包含私人草稿和私密讨论。超过 1000 条明确标注截断。 |
| 资源预约与审批 | 团队 → 资源预约与占用 | 填资源、用途、开始和结束时间；老师或管理员审批。提交和批准都检查时段冲突，并发审批也不能重复占用。 |
| 文档评论通知 | 文档评论／回复 → 站内通知 | 提醒文档作者和相关参与者，通知可定位评论；撤销私有分享后不再显示对应通知或计入未读。 |
| 文档确认与更新提醒 N7 | 文档顶部 → 请成员确认 | 选择有访问权限的成员核对此版。正文改动或恢复历史版本后旧确认失效，并提醒重新核对。 |
| 迭代趋势／燃尽图 | 迭代详情 | 展示每天最后一次采样的剩余主任务、总量和范围变化。历史无样本的日期留空，不倒推虚构。 |
| 讨论／复盘转任务 | 团队评论、任务讨论、已保存复盘 → 转为任务 | 确认标题和说明后创建真实任务，保留来源。私密讨论须明确确认公开结论，老师不能因此看到原讨论。 |

## REA 研究如何落到本项目

本轮用 REA 6.4 观察官方公开帮助页的页面结构、文字和图片，再通过本项目自己的测试验证实现。没有登录商业平台的业务界面，也不声称获得其私有代码、内部协议或完成供应商认证。

| 参考平台 | 借鉴的交互 | 课程场景中的简化 |
| --- | --- | --- |
| 飞书 | 邀请有效期、加入审核、会议室审批、文档通知、本地记录 | 只保留单级审核和站内通知；资源按团队管理；恢复先预览后合并。 |
| Notion／Confluence | 工作区危险操作、正文状态和验证、日历连接与拖动 | 输入名称确认解散；按正文版本确认；拖动先核对冲突，不增加企业配置后台。 |
| Trello | 附件与卡片并列，预览、下载和删除 | 文件放在对应任务／文档附近，权限随内容，保留上传状态和失败重试。 |
| Jira | 迭代燃尽图、范围变化与统计说明 | 用主任务数量，避免故事点配置和子任务重复计数；不生成不存在的历史。 |
| Outlook／Google Calendar／CalDAV 标准 | 导入与订阅区分、分享授权、条件更新 | 先做标准 ICS／CalDAV；明确读取、发布和只读分享的不同权限。 |

## 数据与部署

- 增量迁移为 0023、0024、0025；不重置原业务数据、账号密码、AI 密钥或 Cloudflare 配置。
- 上传文件存于独立 Docker 数据卷 `attachments_data`，不放公开静态目录。每次下载、预览和删除都重新检查当前权限。
- 默认项目 250 MB、个人 500 MB、全站 2 GB；删除文件先撤销访问，保留一小时后清理，便于数据库和文件配对备份。已正式提交引用的附件保留。
- `node scripts/ops.mjs backup` 生成数据库、附件 tar 和校验清单；`restore-drill` 恢复到新数据库和独立文件目录，并核对附件大小、SHA-256。恢复演练不会覆盖线上库。
- 日历 URL／凭据加密保存。后台刷新、趋势采样和附件清理复用现有定时服务。

## 测试与实际边界

验证使用独立测试数据库和桌面浏览器，覆盖权限、私密内容、并发、重试、恢复与真实文件上传。完整集成结果以仓库中的 [本轮验证记录](verification/course-extensions-20261020.json) 为准。

标准 CalDAV 已完成 REPORT／PUT／ETag 冲突等协议回归；尚未连接用户真实第三方日历账号。用户填入具体日历集合地址和应用专用密码后，仍需实际供应商互通测试。没有借用他人账号，未自动公开私人安排。真实外部 AI 付费调用继续按原设置另行验证。

尚未增加的候选功能单独见 [剩余功能清单](remaining-features-20261020.md)。旧日期文档中的“未实现”是当时状态，不代替本页。
