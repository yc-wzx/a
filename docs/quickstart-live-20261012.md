## 现在可用

- [五分钟新手教程](https://weidu-agilecampus.pw/help)：登录后按负责人、组员、导师角色上手，顶部「页面引导」可关闭和重开。
- 项目看板里程碑：管理员可先看关联数量再确认删除；任务、成果与历史版本保留，解除当前关联。
- 任务详情：继续使用已有删除接口，明确提醒主任务及子任务会一起删除。
- [我的 AI 助手](https://weidu-agilecampus.pw/settings#my-ai)：每人选择服务商和模型、保存自己的 API 密钥、命名助手、设置表达偏好、测试连接、替换或删除配置。
- 聊天默认个人会话；项目共享会话主动选择。聊天、迭代草案、课表规划中的 AI 都读取当前登录人的配置，不使用其他人的密钥或服务器共享密钥。

开源依据、实现和密钥维护见 [本轮功能说明](quickstart-personal-ai-20261012.md)，可发群的 [Markdown 教程](quickstart.md)。
