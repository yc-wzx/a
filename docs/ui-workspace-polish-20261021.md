# 桌面界面调整与操作说明

本轮落实已确认的助手、看板、居中任务和文档四页方案。减少长期占位的面板及重复边框，让常用内容先显示，管理操作按需展开。

## 个人助手

- 左侧放新对话、新建项目及按项目排列的个人历史；历史的更多菜单保留重命名、删除。
- 拖动历史栏与对话区之间的分隔线调整宽度。当前浏览器按账号记住设置，刷新仍保留；双击复位，聚焦分隔线后也可用左右方向键调整。
- 右侧对话占用剩余页面高度，输入框在底部。上下文与偏好记忆点击后展开，关闭后恢复完整对话空间。
- 资料问答、个人模型与密钥设置、流式停止及任务草案确认继续使用原有功能。没有配置个人模型时，不会发送真实 AI 请求。

## 任务看板与居中任务

- 看板、列表和甘特图共用工具栏，筛选和常用筛选展开后操作。负责人、项目说明、里程碑及新建任务保留在紧凑入口中。
- 卡片显示标题、优先级、截止日期、执行成员及标签摘要。拖动把手或展开更多菜单移动任务；展开菜单直接占用卡片内空间，避免被看板滚动边界裁掉。
- 点击任务仅打开一个居中任务窗口。先显示任务信息，点击“编辑任务”再修改；取消未保存修改需要确认，保存期间不可切换内容或取消编辑。
- 检查清单、关联内容、附件及成果提交继续保留。团队评论与任务讨论维持原有访问范围及独立入口，原有任务／沟通宽度调节继续可用。

## 项目文档

- 扩大正文，减少重复的卡片边框；常用格式直接显示，其余格式与导出操作放入更多菜单。
- 文档确认采用紧凑入口；评论、版本、任务关联、引用、AI 和设置使用同一侧栏，按需切换或关闭。
- 评论列表显示在输入框上方；回复、段落定位、解决评论、历史版本、离线恢复及附件功能继续保留。

## 验证范围

在本地独立测试数据上检查侧栏拖动／持久保存／键盘操作、历史恢复／新建／重命名／删除、任务阅读与编辑／取消／保存、团队评论与讨论入口、文档评论写入和工具栏入口；检查 1280 与 1920 像素桌面宽度的布局。真实 AI 服务调用仍依赖各用户自己的配置，本轮不调用付费模型。

完整回归：844 项通过、2 项真实外部服务测试跳过；TypeScript 检查通过，修改文件 ESLint 无错误（保留任务详情既有的 1 条 effect 依赖警告）。浏览器同时验证看板更多菜单的任务移动持久保存与菜单边界。

本轮不增加数据库迁移，也不调整原有业务权限。上线使用原数据库与附件存储，发布前备份，并保留旧镜像回滚路径。
