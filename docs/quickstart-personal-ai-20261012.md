# 2026-10-12 新手教程、删除里程碑与个人 AI

以下是在原有功能上增量增加的内容。

| 新增／调整 | 具体行为 |
|---|---|
| 新手教程 | `/help` 按负责人、组员、指导老师给出五分钟流程；解释项目、里程碑、任务、迭代，提供个人 AI 配置步骤 |
| 页面引导 | 顶部手动打开，按当前页面可见入口提示；中文按钮，可关闭和重看，不强制执行业务操作 |
| 首次提示 | 工作台提示教程入口，关闭状态按账号保存在当前浏览器 |
| 里程碑删除 | 仅当前项目管理员；先预览任务／成果关联数量，再确认；请求幂等、阶段内容变化拒绝旧确认、归档项目禁止修改 |
| 关联数据保护 | 当前任务和成果解除里程碑关联、更新版本；成果工作副本同步解除关联；正式成果版本、阶段反馈快照、迭代历史保留 |
| 任务删除提示 | 复用原有任务详情删除功能，明确提示删除主任务会删除其子任务，不重复新建接口 |
| 个人 AI 配置 | 每个账号保存服务商、模型、密钥、助手名称、表达偏好；保存／测试／替换／删除，空密钥可保持已有值；配置并发修改检查版本 |
| 个人 AI 调用 | 原聊天、迭代草案、课表规划的 AI 调用按当前登录人取配置，未配置不使用他人的密钥或共享服务器密钥；规则规划不受影响 |
| 默认个人会话 | 项目看板和 AI 页面默认仅本人可见；主动选择的项目共享会话保留，并继续标注共享范围 |

## 开源模块取舍

| 模块 | 依据 | 本项目实际使用 |
|---|---|---|
| [Driver.js](https://github.com/kamranahmedse/driver.js) | MIT，专注页面高亮与步骤提示，无需引入整套产品 | 新增固定版本 `1.9.0`，手动打开时加载引导 JS；中文内容由本项目编写；许可证在 `docs/licenses/driver.js-MIT.txt` |
| [Vercel AI SDK](https://github.com/vercel/ai) / [OpenAI Compatible Provider](https://github.com/vercel/ai/blob/main/packages/openai-compatible/README.md) | Apache-2.0，可按实例指定 API 密钥、接口地址和模型 | 复用仓库现有 AI SDK v5 和兼容 provider，增加个人配置层，不升级主版本、不另建聊天平台 |
| [LobeHub / LobeChat](https://github.com/lobehub/lobehub) | 是完整助手产品，当前[社区许可证](https://github.com/lobehub/lobehub/blob/main/LICENSE)有附加条件 | 调研个人配置交互，未复制代码、未作为内置服务；当前网站只增加必要字段与原有助手入口 |

内置服务商地址参考 [DeepSeek 官方 API](https://api-docs.deepseek.com/) 和 [阿里云百炼兼容接口](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)。模型名称可自行填写，应以个人服务商控制台支持的名称为准。服务商使用额度和费用由用户自己的账号承担。

## 部署与密钥

新增迁移 `0015_personal_ai_settings.sql`，只增加个人 AI 设置表，不修改现有业务表。API 密钥使用 AES-256-GCM 加密，随机 nonce，以账号 ID 作为认证关联信息；摘要返回值不含密钥或密文。密钥清除后保留版本号，避免旧页面覆盖后来重新创建的配置。

服务器配置独立的 `AI_SETTINGS_ENCRYPTION_KEY`（随机 32 字节，64 位十六进制），不与 `AUTH_SECRET` 等复用。发布与数据库恢复必须保留此主密钥；遗失后已有密钥无法解密，需要用户重新配置。不要提交 `.env`、API 密钥或主密钥到 GitHub、群聊或报告。

`AI_ALLOWED_BASE_URLS` 可按逗号配置负责人批准的 HTTPS 兼容 API 地址。用户不能填任意网址、内网 IP、账号参数或非标准端口；模型请求禁止跟随重定向。服务商错误转换为安全提示，不记录或回传 SDK 原始异常。

个人表达偏好只影响表达方式，不改变项目权限、可选任务边界和草案人工确认规则。默认个人聊天仍只使用已有授权项目上下文，不额外向其他成员公开配置。
